3. Investigate a failure
```
Investigate the latest failed build of <JOB_NAME>. Inspect the build details and console output. Identify the failure point, explain the likely root cause, and suggest the next troubleshooting steps.
```

4. Do cross-job analysis

```
Analyze the failed and unstable builds from the last hour. Look for common failure patterns across jobs and determine whether multiple failures could have a shared cause.
```

5. Let the AI take action

After identifying failed jobs:

```
For each failed job, check whether the failure appears transient based on the recent build history. For jobs that appear transient, trigger a new build. Do not trigger builds for jobs where the failure appears persistent. Explain your decision for each job.
```

6. Verify the action

After it triggers builds:

```
Monitor the builds I just triggered and report their final status. For any build that fails again, inspect the console log and explain what happened.
```
